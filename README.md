# mindfulopus notes

## 1. how to boot up the site

```bash
Commnad + Space + "Terminal"
cd ~/Desktop/mindfulopus-website
npm run develop 
```

## 2. Helpful Commands

```bash
# search for page
Command + P + "base.njk" 

# save page
Command + S 

# cut text
Command X

# copy text
Command C

# paste text
Command V

# undo command
Command Z

# Highlight text
Command + Shift + RightArrow
```

## 3. how to push/deploy

to push the site changes, these are the commands to run:

```bash
git add . && git commit -m "add text" && git push 
```
